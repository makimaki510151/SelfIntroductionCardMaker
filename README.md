# 自己紹介カードメーカー

写真と名前からはじめて、欄を足し、デザインと書体を選んで、自己紹介カードの画像を作るページです。ビルドは不要です。このフォルダをそのまま GitHub Pages に置けます。

## できること

- 写真と名前は最初からあります
- テンプレートを選んで欄を足せます。基本、仕事・学校、人となり、好き、日常、これから、つながりまで、すべて書くとその人の輪郭が伝わります
- テンプレートにない欄も、名前をつけて自由に追加できます
- 12種類のカードデザイン、写真の形、1列と2列
- 写真の位置と拡大率を、つまみかドラッグで調整できます
- 欄の文字と内容の文字で、書体・色・大きさを別々に選べます
- 欄ごとに「この欄だけ変える」から、その欄だけの書体と色も変えられます
- 書き出しは16:9です。画像（1枚ならPNG、複数ならまとめたファイル）と、同じ見た目のPDFを保存できます
- 入力はこのブラウザに自動保存されます。バックアップの JSON でも持ち出せます

## 公開する

1. このフォルダの中身を GitHub リポジトリに入れます
2. リポジトリの Settings → Pages を開きます
3. Build and deployment は Deploy from a branch、Branch は `main`、Folder は `/ (root)` にします
4. ビルドコマンドは空のままでかまいません

書体は Google Fonts から読み込みます。画像化に使う [html2canvas 1.4.1](https://html2canvas.hertzen.com/)（MIT）は `vendor/` に同梱しています。
